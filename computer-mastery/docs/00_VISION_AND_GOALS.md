# Vision and Goals

## Long-Term Vision

Build a homeschool-style computer science and computer engineering education with the seriousness, depth, and rigor associated with an elite technical program.

The goal is not credential imitation. The goal is capability.

Over time, this program should produce an engineer who can move through multiple layers of the machine:

```text
Application Code
      ↓
Libraries / Runtime
      ↓
Compiler / Linker / ABI
      ↓
Executable / Binary Format
      ↓
Process / Threads / Memory
      ↓
Operating System
      ↓
Networking / Storage / Devices
      ↓
CPU / Architecture
      ↓
Hardware
```

Security crosses every layer.

## Career Goal

Become unusually capable at professional engineering work, especially difficult systems problems that cross abstraction boundaries.

Examples include platform-specific crashes, memory corruption, deadlocks and race conditions, engine or SDK integration failures, performance problems, networking failures, build and linker issues, binary inspection, process and OS behavior, incident investigation, defensive security, and custom internal tooling.

## Intellectual Goal

Develop enough breadth to understand the major fields of computer science and enough depth to become an authority in selected areas.

World-class authority is expected to be a multi-year path. It eventually requires textbooks, primary documentation, source code, academic papers, reproducing experiments, contributing tools or research, questioning accepted assumptions, and specializing deeply.

## The Desired Identity

The target is not “someone who knows lots of syntax.”

The target is:

> Someone who can be handed an unfamiliar technical problem and confidently begin discovering the truth.

The desired reaction to a mysterious system is:

> I do not know the answer yet, but I know how to find out.

## What This Curriculum Is Not

This is not a LeetCode-only program, a tutorial playlist, a sequence of toy syntax exercises, a collection of disconnected security tricks, an AI-generated-code curriculum, or a race to finish topics.

Depth matters more than speed.
